# Upper bound is required, not cosmetic. mcp 2.0.0 removed the low-level
# Server decorator API that core.build_server() uses (@app.list_tools,
# @app.call_tool, @app.list_prompts, @app.get_prompt). Those decorators run
# only at server start-up, inside build_server(), so the test suite passes
# against mcp 2.x while the server itself fails to start. Pyright is what
# catches it. Lift the bound only after porting core.py to the 2.x API.
mcp>=1.10.0,<2.0.0
python-dotenv>=1.0.0
requests>=2.31.0
pydantic>=2.0.0
